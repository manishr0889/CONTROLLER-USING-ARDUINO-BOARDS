# CONTROLLER-USING-ARDUINO-BOARDS
A compact DIY game controller project built using Arduino boards for controlling PC games with physical push buttons.
This project maps arcade-style controls like Up, Down, Left, Right, Jump, Fire, X, O, Square, Triangle to keyboard inputs, allowing the Arduino to work as a custom gaming controller.
Features
🎮 Arduino-based custom game controller
⌨️ Keyboard emulation for PC gaming
🔘 Multiple push-button inputs
⚡ Low-cost and beginner-friendly setup
🕹️ Compatible with retro and lightweight PC games
🔌 Easy USB connectivity
Hardware Used
Arduino Board (Uno / Mega / Micro / R4 WiFi depending on setup)
Push Buttons
Jumper Wires
Breadboard
USB Cable
Software & Libraries
Arduino IDE
Keyboard Library (for supported boards)
Applications
Retro gaming controller
DIY arcade projects
Game development testing
Educational embedded systems project
Project Goal
To create a simple and affordable custom controller using Arduino boards that can interact with PC games through keyboard input emulation.
